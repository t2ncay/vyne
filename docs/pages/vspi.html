Embedded Buses

vspi

Typed, range-checked SPI master helpers for the Arduino Uno target.

Quick factValue
Modulevspi
Importuse external "vspi/vspi.vy";
Depends onarduino (AVR target)
StatusUnstable — the public surface may change between releases.
Generated reference

This page is generated from the library's in-repo manual (vyne/modules/external/vspi/README.md) so signatures and behaviour stay aligned with the source tree. Examples assume a desktop target unless the text says otherwise.

vspi is the typed wrapper over the AVR SPI bindings. It validates the clock, data mode, and byte/word ranges before the native call, so a bad constant produces a status code instead of a silently truncated transfer.

 vyne snippetvyne
use native arduino; use external "vspi/vspi.vy"; vspi.begin(); vspi.set(1000000, 0); # 1 MHz, mode 0 id :: Int64 := vspi.transfer(0x9F); # e.g. JEDEC ID on a flash chip vspi.end_transaction(); vspi.end();

Requirements

  • Target: Arduino Uno R3 (vynec --arduino uno ...). Desktop builds do not define arduino_spi_*.
  • The AVR build integration compiles the bundled SPI library and adds vendor/arduino/libraries/SPI/src to the include path automatically.
  • Uno pinout: MOSI = D11, MISO = D12, SCK = D13, SS = D10 (drive SS manually for the device you are talking to).

Return codes

CodeMeaning
0Success
-1Transfer failed (reserved; the AVR path does not fail)
-2Invalid clock (must be > 0)
-3Invalid mode (0..3), byte (0..255), or word (0..65535)

Loopback test

examples/arduino/spi_loopback.vy sends a pattern and compares the received byte. Jumper D11 (MOSI) to D12 (MISO), flash, and open the serial monitor at 115200. With the jumper removed the received bytes are not a reliable echo, which is expected.

Scope

This first slice exposes byte and word transfers. Multi-byte block transfers (transfer_bytes) need a buffer ABI on the MCU runtime and are a follow-up.
