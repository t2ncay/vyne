voptim

In-place optimizers (SGD, momentum, Adam, AdamW, RMSProp, Adagrad) and learning-rate schedules.

Depends onnone beyond the core runtime
StatusUnstable — the public surface may change between releases.
Generated reference

This page is generated from the library's in-repo manual (vyne/modules/external/voptim/README.md) so signatures and behaviour stay aligned with the source tree. Examples assume a desktop target unless the text says otherwise.

voptim is the optimizer layer for Vyne: SGD, momentum/nesterov, Adam, AdamW, RMSProp, Adagrad, and the common learning-rate schedules. It works on flat Array<Float64> buffers, so it composes with vlin.Matrix by passing matrix.data and matrix.size().

The design rule is the same as the rest of the numerical stack: build state once, then update in place. Every *_step function writes the parameter buffer and returns nothing. The update kernels allocate nothing; wrappers pay only the current function-call frame at the call boundary.

 vyne snippetvyne
use external "voptim/voptim.vy"; params :: Array<Float64> := [2.0, -3.0]; opt :: voptim.AdamState := voptim.adam_new(params, 0.9, 0.999, 1e-8); through step :: 0..199 -> loop { grads :: voptim.Series := voptim.Series([params[0], params[1]], 2); lr :: Float64 := voptim.cosine(step, 0.05, 200); voptim.adam_step(opt, grads, lr); }; out(params[0] + ", " + params[1]); # near zero for f(w)=0.5||w||^2

adam_step and adamw_step increment state.t and compute the bias corrections internally. state.weight_decay is zero for plain Adam.

step is zero-based.

Zero-copy setup

The constructors copy a boxed Array once. If you already have a typed buffer, construct the state directly:

 vyne snippetvyne
s :: voptim.AdamState := voptim.AdamState(params, m, v, 0.9, 0.999, 1e-8, 0.0, 0, n);

The parameter and moment arrays are shared, not copied, so every step updates the caller's buffers.

Integrating with vlin

 vyne snippetvyne
use external "vlin/vlin.vy"; use external "voptim/voptim.vy"; w :: vlin.Types.Matrix := vlin.xavier(64, 16, 42); opt :: voptim.AdamState := voptim.adam_new([/* copy or wrap w.data */], 0.9, 0.999, 1e-8);

For zero-copy use, construct an AdamState from w.data and its length directly. Gradient buffers are ordinary Array<Float64> values.

Validation

examples/libs/voptim_test.vy checks:

  • each schedule at known steps,
  • SGD/momentum/nesterov/Adam/AdamW/RMSProp/Adagrad reduce a quadratic,
  • AdamW shrinks a zero-gradient parameter,
  • AdamW decays a zero-gradient parameter.

examples/libs/voptim_bench.vy times 100k-parameter updates.
