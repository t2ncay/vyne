Graphics Showcase

Run the managed raylib project, Bodycam Horror, and Sector Shift; verify rendering, resource cleanup, and audio.

vraylib integrates vendored raylib 6.2, raymath, and rlgl into compiled desktop Vyne. The managed facade adds App-owned resources, frame arena cleanup, cameras, named shader uniforms, resizable render targets, streamed music, and one-shot sound.

Start with the portable project

 shell snippetshell
vynec build examples/projects/raylib-showcase vynec run examples/projects/raylib-showcase

This small orbit-camera project needs no ignored historical assets. The first build compiles vendored raylib into the user cache; later builds reuse it. Install GCC, CMake, make, and your platform's graphics development dependencies as described in Installation. Rendering needs an OpenGL context. The native library is statically linked; no raylib DLL needs copying.

Bodycam Horror

From the repository root:

 shell snippetshell
vynec --run examples/graphics/camera_test.vy

The restored scene includes the original 16 buildings, model animations, fog, VHS/scanline post-processing, VCR font, ambient audio, and recording overlay. The managed API caches typed assets, updates music each frame, tracks render passes, caches named uniform locations, and resizes screen-following targets. Movement/animation use elapsed time; collision, crouch, and jumping remain scene logic.

The original OBJ/MTL, texture, font, and audio files in examples/assets/ are local and ignored by Git. Preserve their relative dependencies. They are needed for this full scene, and are not downloadable assets bundled with the site. Missing assets produce named errors and managed cleanup.

Sector Shift / Sector 4 Incident

 shell snippetshell
vynec --run examples/graphics/sector_shift.vy

The managed horror corridor retains the paired walls, stalker billboard, radio log, bodycam malfunction, blackouts, recording overlay, and ending. WASD moves, Shift sprints, Tab toggles mouse capture, F11 toggles fullscreen, and Escape exits. The default is 1920×1080 fullscreen at 60 FPS.

Sector fog preserves billboard transparency. sector_fog.fs exposes cameraPos and u_density; sector_vhs.fs exposes time, renderSize, and noise_amount. The radio plays once after Z=100. After Z=150 the App enables a fixed native hard saturator at drive 0.8. Ambient music streams automatically; radio uses managed Sound. The native audio callback uses no Vyne calls, allocations, or locks.

Local assets required under examples/assets/: wall.jpeg, asphalt_road_3.jpg, ebil_qehbe.png, VCR_OSD_MONO_1.001.ttf, akira.wav, and radio_log.wav. Shader sources are committed; original media are ignored.

Acceptance tests

From the repository root:

 shell snippetshell
python scripts/generate_vraylib.py --check python examples/projects/raylib-showcase/tests/run.py python examples/projects/raylib-showcase/tests/run.py --graphics python examples/projects/raylib-showcase/tests/run.py --graphics --camera --audio python examples/projects/raylib-showcase/tests/run.py --graphics --sector --audio # Linux virtual-display and native sanitizer checks xvfb-run -a python3 examples/projects/raylib-showcase/tests/run.py --graphics --sanitize

Core tests need no graphics/audio device. --graphics checks rendered pixels, managed targets/uniforms/passes, and asset-independent Sector shaders. CPU tests cover Sector state thresholds/freeze timing and saturation DSP. --camera and --sector require their local assets; --audio opts into a real audio device. Full Sector acceptance checks one radio play, a live saturation callback, the ending sequence, and zero remaining native handles. --sanitize instruments the native bridge and vendored library. VYNEC selects the compiler executable.

See the project acceptance guide and Sector Shift details.
