Graphics Showcase

Run the managed raylib project, Bodycam Horror, and Sector Shift; verify rendering, resource cleanup, and audio.

vraylib integrates vendored raylib 6.2, raymath, and rlgl into compiled desktop Vyne. The managed facade adds App-owned resources, frame arena cleanup, cameras, named shader uniforms, resizable render targets, streamed music, and one-shot sound.

Start with the portable project

 shell snippetshell
vynec build examples/projects/raylib-showcase vynec run examples/projects/raylib-showcase

This small orbit-camera project needs no ignored historical assets. The first build compiles vendored raylib into the user cache; later builds reuse it. Install GCC, CMake, make, and your platform's graphics development dependencies as described in Installation. Rendering needs an OpenGL context. The native library is statically linked; no raylib DLL needs copying.

Bodycam Horror

From the repository root:

 shell snippetshell
vynec --run examples/graphics/camera_test.vy

The restored scene includes the original 16 buildings, model animations, fog, VHS/scanline post-processing, VCR font, ambient audio, and recording overlay. The managed API caches typed assets, updates music each frame, tracks render passes, caches named uniform locations, and resizes screen-following targets. Movement/animation use elapsed time; collision, crouch, and jumping remain scene logic.

VMGE / Vyne Mini Game Engine

The historical map builder and loader now launch the project under examples/projects/vmge/. From the repository root:

 shell snippetshell
vynec --run examples/projects/vmge/src/main.vy vynec --run examples/graphics/map_builder.vy vynec --run examples/graphics/map_load_test.vy

Inside the VMGE project directory, use vynec build and vynec run. The default VYNE_VMGE_MODE=scene opens the Inter-based 3D studio: hierarchy, grouped inspector, transform gizmos, cached asset browsing/imports, orthographic views, resource map brushes, seeded terrain/sculpting and isolated Play/Stop. New/Open/Exit/native close support Save/Discard/Cancel; scene saves use atomic replacement. Build the compiler from this revision for its exception-lifetime and VFS fixes. editor edits historical maps; play explores them. The map path defaults to tau_map.dat; an explicitly requested missing viewer map is an error. Without an explicit map, the viewer can fall back to the committed demo.

For the portable demo in PowerShell:

 powershell snippetpowershell
$env:VYNE_VMGE_MODE = "play" $env:VYNE_VMGE_ASSETS = "procedural" $env:VYNE_VMGE_MAP = "examples/projects/vmge/maps/demo.dat" vynec --run examples/projects/vmge/src/main.vy

The editor supports WASD flight, Shift/Ctrl height, 1–8 texture selection, Space/left-click placement, Backspace/right-click removal, J save, and K OBJ geometry export. Play mode provides sprint, crouch/headroom, jump, wall sliding, cube-top landing, fog, VHS, scanlines and optional streamed ambient audio. Both use Tab cursor capture, F11 fullscreen, Escape exit and delta-time motion.

For the hybrid-world studio, use VYNE_VMGE_MODE=scene, procedural assets, and VYNE_VMGE_SCENE=examples/projects/vmge/scenes/world-island.vscene. Choose Save As to preserve the bundled scene. Settings exposes seed/size/spacing/amplitude, frequency/octaves/persistence and spawn-pad radius. Preview before Apply; Paint, Erase and Rectangle build cells alongside terrain; Raise/Lower/Flatten/Smooth sculpt it. Undo records one action per stroke. F6 starts/stops Play.

One scene-owned resource holds up to 4,096 cells and 64×64 terrain quads without consuming node slots. Exact triangle sampling drives drawing, picking and terrain support, with a 50° walking limit. Rendering is currently bounded immediate-mode drawing rather than chunk/LOD streaming. OBJ/DAT studio exports contain resource map cells only. Portable imports support self-contained GLB/images; dependency trees for other model formats must be copied or referenced explicitly.

App-owned resources, reusable cube models and preallocated map storage preserve edits across managed frame cleanup. Shader targets follow window resizing. Procedural textures and the committed demo need no ignored historical media; the original eight-slot palette and map format are also supported.

Sector Shift / Sector 4 Incident

 shell snippetshell
vynec --run examples/graphics/sector_shift.vy

The managed horror corridor retains the paired walls, stalker billboard, radio log, bodycam malfunction, blackouts, recording overlay, and ending. WASD moves, Shift sprints, Tab toggles mouse capture, F11 toggles fullscreen, and Escape exits. The default is 1920×1080 fullscreen at 60 FPS.

Sector fog preserves billboard transparency. sector_fog.fs exposes cameraPos and u_density; sector_vhs.fs exposes time, renderSize, and noise_amount. The radio plays once after Z=100. After Z=150 the App enables a fixed native hard saturator at drive 0.8. Ambient music streams automatically; radio uses managed Sound. The native audio callback uses no Vyne calls, allocations, or locks.

Local assets required under examples/assets/: wall.jpeg, asphalt_road_3.jpg, ebil_qehbe.png, VCR_OSD_MONO_1.001.ttf, akira.wav, and radio_log.wav. Shader sources are committed; original media are ignored.

Acceptance tests

Core tests need no graphics/audio device. --graphics checks rendered pixels, managed targets/uniforms/passes, and asset-independent Sector shaders. CPU tests cover Sector state thresholds/freeze timing and saturation DSP. --camera and --sector require their local assets; --audio opts into a real audio device. Full Sector acceptance checks one radio play, a live saturation callback, the ending sequence, and zero remaining native handles. --sanitize instruments the native bridge and vendored library. VYNEC selects the compiler executable.
