Helpers

Single-file Helpers

Small standalone modules for terminal color, unit conversion, plotting, and strings.

These modules live directly under vyne/modules/external/ rather than in their own directory. They are small convenience layers, kept for compatibility. Some were written against earlier syntax; prefer the maintained libraries when they cover the task.

Import them with an external path:

 vyne snippetvyne
use external "vcolors.vy"; use external "vconvert.vy"; use external "vstring.vy"; use external "vplot.vy";

Older code uses use lib "vcolors.vy";. That form is still accepted, but use external is the current spelling.

vcolors

ANSI terminal styling. Exports style wrappers and a palette.

GroupNames
Foregroundblack, red, green, yellow, blue, magenta, cyan, white, gray
Bright foregroundboldBlack, boldRed, boldGreen, boldYellow, boldBlue, boldMagenta, boldCyan, boldWhite
BackgroundonBlack, onRed, onGreen, onYellow, onBlue, onMagenta, onCyan, onWhite
Stylebold, dim, italic, underline, blink, reverse, hidden, strikethrough
Semanticsuccess, error, warning, info, hint
Customrgb(r, g, b, text), bgRgb(r, g, b, text), rainbow(text), box(text), banner(text), rule()
 vyne snippetvyne
use external "vcolors.vy"; out(vcolors.bold("=== training ===")); out(vcolors.green("done")); out(vcolors.red("failed")); out(vcolors.rgb(120, 200, 255, "custom"));

The wrappers return strings with ANSI escapes. Disable color at the terminal level (NO_COLOR) or simply do not use the wrappers in machine-readable output.

vconvert

Unit conversion helpers. All take and return numbers.

CategoryFunctions
TemperaturecelsiusToFahrenheit, celsiusToKelvin, fahrenheitToCelsius, fahrenheitToKelvin, kelvinToCelsius, kelvinToFahrenheit
DistancekmToMiles, milesToKm, kmToMeter, meterToKm, meterToCm, cmToMeter, cmToMm, mmToCm

 vyne snippetvyne
use external "vconvert.vy"; out(vconvert.celsiusToFahrenheit(100.0)); # 212 out(vconvert.kmToMiles(10.0)); out(vconvert.hoursToMin(2.0)); # 120

FunctionMeaning
upper(s)Uppercase
lower(s)Lowercase
title(s)Title case
swapCase(s)Swap case per character
split(s, delimiter)Split into an array

 vyne snippetvyne
use external "vstring.vy"; out(vstring.upper("vyne")); # VYNE out(vstring.title("hello world")); # Hello World out(vstring.join(["a", "b"], "-")); # a-b

vplot

A minimal bar-chart helper that prints bars to stdout.

 vyne snippetvyne
use external "vplot.vy"; vplot.bar_chart([3, 7, 2, 9], 10);

For real plotting, use vtermplot: line, scatter, bar, histogram, heatmap, and sparkline with axes, labels, Unicode/ASCII themes, and file export.

Compatibility note

These helpers predate the current kernel/wrapper library layout. They are not part of the numerical stack's tested surface and may use older declaration forms. New code should prefer:

  • vtermplot for terminal charts, or vplot/vplot.vy for colorful images and live ESP32 plots;
  • the built-in string methods or vstring instead of ad-hoc loops;
  • explicit conversions instead of relying on older untyped helper signatures.
