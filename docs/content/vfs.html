Standard Library

VFS

Filesystem reads, writes, directory walking, globbing, and path manipulation.

vfs is the desktop filesystem module. Import it with use native vfs;. It has no AVR implementation; the Uno has no filesystem.

Reading

FunctionResultNotes
vfs.read(path)String / nullWhole file in binary mode; null on failure.
vfs.read_lines(path)ArrayLines without \n (and without a trailing \r).
vfs.read_bytes(path)ArrayBoxed Int64 bytes, 0..255.
 vyne snippetvyne
use native vfs; text := vfs.read("data/input.csv"); lines := vfs.read_lines("data/input.txt"); bytes := vfs.read_bytes("data/model.bin");

Writing

FunctionResultNotes
vfs.write(path, text)BoolTruncate and write a string.
vfs.append(path, text)BoolAppend a string.
vfs.write_lines(path, lines)BoolWrite each line followed by \n.
vfs.write_bytes(path, bytes)BoolWrite Int64 bytes masked to 0..255.

vfs.write("out.txt", "hello\n"); vfs.append("out.txt", "world\n"); vfs.write_lines("out.txt", ["a", "b", "c"]);

Memory and errors

  • vfs.read allocates the file contents in the arena. Inside a region, the string is reclaimed at the closing brace.
  • File-open failures return null (reads) or false (writes), not exceptions. Check the result when the file is required.
  • Paths are UTF-8. Windows separators are handled internally; use / or \ as appropriate.
