Variables & Data types

Vyne provides a robust set of built-in data types tailored for algorithmic precision and system-level performance.

Type Description Example Syntax
Int64 64-bit signed integer for whole numbers. age :: Int64 = 20;
Float64 64-bit double-precision floating point. sample_rate :: Float64 = 44100.0;
String UTF-8 character sequence. "Hello Vyne"
Boolean Logical true or false. is_valid = true;
Array Dynamic heterogeneous list. [1, "text", 3.14]
Heterogeneous Arrays

Unlike C++, Vyne arrays can hold multiple data types simultaneously.

Numbers

Numbers in Vyne encompass both integers and decimals. You can use explicit typing for strict control.

explicit_decl.vy 
// variableName :: Type = value
age :: Int64 = 30;
GPA :: Float64 = 3.42;
Type Inference

Vyne automatically detects the variable type if you omit the explicit declaration, keeping your code clean.

inferred_decl.vy 
age = 30;   // automatically Int64
GPA = 3.42; // automatically Float64

Arithmetic

Standard mathematical operations optimized for the Vyne Virtual Machine.

Symbol Operation Example
+ / - Addition and Subtraction 50 - 26
* / / Multiplication and Division 48 / 6
== / != Equality Comparisons age == 20

Strings

Strings are first-class citizens in Vyne with native concatenation and indexing support.

strings.vy 
name = "vyne";
type = "language";

// Concatenation
full = name + " " + type; // "vyne language"

// Indexing
char = name[0]; // 'v'
Warning: String values MUST be enclosed in double quotes (").
