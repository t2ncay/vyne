The Vyne
language

Where C meets creativity. Build games, audio tools, and web servers — all in one language.

A C‑flavored scripting language with optional strict typing, structs via interface, and a standard library that reaches from VMath to VGLib 3D and VServ HTTP. Run it on the tree‑walking interpreter, or lower it straight to native C.

Basics

syntax

Vyne is a hybrid, interpreted language with C-style syntax, strong type inference, and a rich standard library. Everything is an expression.

hello.vy
// variable with type inference msg = "vyne" + " language"; out(msg); // => "vyne language"
Implicit typing
Use = for type inference. Explicit types via ::.
Rulesets
Toggle warnings, strict mode, memory limits with ruleset { warnings, strict }.

Types

built-in

Vyne provides Int64, Float64, String, Array, Map, Bool and null.

Type Example Notes

Float64 pi :: Float64 = 3.14; double precision
String "hello" UTF‑8, immutable
Array [1, "two", 3.0] heterogeneous
Map { "key": 42 } string keys only

Control flow

if / while / through

Standard if, while and the functional through operator for collections.

control.vy
// through with collect doubled = through x :: [1,2,3] -> collect { x * 2 }; // [2,4,6] // filter evens = through n :: 0..10 -> filter { n % 2 == 0 };

Functions

fn

First‑class functions with explicit types or inference, recursion, and closures.

fn.vy
fn add(a :: Int64, b :: Int64) -> Int64 { return a + b; } fn mul(x, y) { x * y } // inferred

Enums

enum

Named integer constants declared with enum. Members auto‑increment from the previous value, and an explicit = N resets the counter.

direction.vy
enum Direction { North, East, South = 10, West } // North = 0, East = 1, South = 10, West = 11 out(Direction.South); // => 10

Structs & interfaces

interface

Vyne has no separate struct keyword — an interface block declares typed fields and method bodies together, and doubles as a positional constructor when called.

shapes.vy
interface Circle { r :: Float64; area() -> Float64 { return r * r * 3.14159; } } c = Circle(4.0); // fields fill positionally out(c.area());
Value semantics
Struct instances deep‑copy their fields on assignment; method tables are shared, so behavior never gets duplicated.
Checked calls
Method calls validate argument count, argument types, and the declared return type before and after the call runs.

Error handling

try / catch / finally

try must be followed by catch, finally, or both. An unnamed catch binds the error to _err by default.

safe.vy
try { risky(); throw "boom"; } catch (err) { out(err); } finally { cleanup(); }
throw
Takes an optional expression — throw; on its own is valid too.
defer
defer stmt; queues a single statement to run when the enclosing scope exits.

Rulesets

engine config

Architecture

engine

One AST, two ways to run it: a tree‑walking interpreter for fast iteration, or a C transpiler for a standalone native binary.

Lexer
tokenize() streams a flat vector<Token>, handling string interpolation ("{expr}") inline as it scans.
Parser
A recursive‑descent Parser builds a typed unique_ptr<ASTNode> tree, tracking scopes to warn on shadowed or unused variables.
Interpreter
Each node's evaluate(env, scopeId) walks the tree directly against a SymbolContainer keyed by scope.
Transpiler
Codegen + C_Emitter lower the same AST into a single C translation unit, then hand off to arena_free_all() at exit.
Value model
Value is a tagged union — primitives live inline, while Array / Map / Struct / Function / Module are boxed behind shared_ptr<VyneObject>.
StringPool
Identifiers and field names are interned once into a global pool, so symbol lookups compare uint32_t ids instead of strings.

Saturation — distortion modes

5 modes
Mode 0 — Soft Tube
Smooth tanh() saturation. Warm, musical distortion. Ideal for analog warmth.
Mode 1 — Hard Clip
Aggressive brickwall clipping. Creates punchy, in-your-face character.
Mode 2 — Asymmetric
Different curves for positive and negative peaks. Adds odd/even harmonic imbalance for vintage character.
Mode 3 — Tape
Polynomial tape saturation. Smooth compression with natural soft-clipping. Classic reel-to-reel sound.

Complete Example — full REST API

working server
api.vy
module vserv; module vcore; // Create app app = vserv.create_app(); // Logger middleware fn logger(req, res, next) { vcore.out("[" + req.method + "] " + req.path); next(); }; vserv.app_use(app, logger); // GET /hello vserv.app_get(app, "/hello", fn(req, res) { vserv.send(res, "Hello, World!"); }); // POST /api/users vserv.app_post(app, "/api/users", fn(req, res) { data = req.body; vserv.send_json(res, { "created": true, "data": data }); }); // Static files vserv.app_get(app, "/static/*", fn(req, res) { file_path = req.path; res = vserv.serve_file(file_path); vserv.send(res); }); // Start server vserv.app_listen(app, 3000); vcore.out("🚀 Server running on port 3000");
This complete example demonstrates a production-ready REST API with logging middleware, JSON endpoints, static file serving, and error handling. Run it with vynec api.vy to start your server.
VServ runs a native C HTTP server with no external dependencies. Each request is handled in a non-blocking loop with support for WebSocket upgrades, middleware chains, and static file serving. The server runs until stopped by the user or an error occurs.
